TradeForge — инструмент-помощник для Path of Exile 2: подготовки и крафта
предметов, оценки рынка, распределения по лавкам, выставления и обновления цен.

> Исходный код программы здесь не публикуется; репозиторий не является
> open-source-дистрибутивом.

## Возможности

| Сценарий | Возможность TradeForge |
|---|---|
| Крафт | Настраиваемый конструктор стадий, валюты и оменов |
| Оценка | Поиск рынка, каскадные запросы, сравнение лотов и сохранённые варианты |
| Продажа | Предпродажа, распределение по лавкам, выставление и обработка дешёвых предметов |
| Репрайс | Обновление цен по правилам и умным условиям, перенос между лавками |
| Поиск продавцов | Удобный поиск по нужному количеству закупаемого предмета |
| Управление | Запуск, пауза, продолжение, остановка, прогресс, логи и предстартовые проверки |
| Поддержка | RU/EN-интерфейс, руководства, Telegram-бот, Discord и явная отправка лога |

## Требования

- Windows 10/11, 64-bit;
- клиент Path of Exile 2;
- область клиента игры ровно `1024×768`;
- русский или английский язык клиента игры;
- доступ к официальному HTTPS-сервису TradeForge;
- действующий лицензионный ключ TradeForge.

## Безопасность и прозрачность

- Для каждого релиза публикуются точная версия, размер и SHA-256.
- Публичный репозиторий не содержит сессий аккаунтов, кошельков, прокси,
  приватных ключей, операторских баз данных или закрытого дерева исходников.
- Установщик пока **не подписан цифровой подписью**, поэтому Windows
  SmartScreen может показать предупреждение. Перед запуском сверяйте SHA-256
  и скачивайте файл только по официальным ссылкам выше.
- В рамках заявленных функций TradeForge может управлять мышью и клавиатурой,
  читать текст предметов из буфера обмена, захватывать настроенные области
  экрана и обращаться к официальному HTTPS-сервису лицензий и цен.
- Полные логи отправляются только после явного действия пользователя во
  встроенной форме поддержки. Не публикуйте полные логи, ключи или cookies в
  GitHub Issues.

Перед установкой прочитайте [Security](SECURITY.md), [Privacy](PRIVACY.md) и
[инструкцию проверки скачанного файла](docs/VERIFY_DOWNLOAD.md).

TradeForge — независимый сторонний инструмент автоматизации, не связанный с
Grinding Gear Games и не одобренный этой компанией. Автоматизация может
противоречить правилам игры и привести к ограничениям или блокировке аккаунта.
TradeForge не гарантирует прибыль, незаметность, непрерывную работу или
отсутствие санкций к аккаунту. Используйте программу только после понимания и
принятия этого риска.
