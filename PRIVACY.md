# Privacy summary

TradeForge is a desktop automation application. Its advertised operation may
process the following data locally:

- configured screen regions and templates;
- mouse and keyboard automation state;
- Path of Exile 2 item text copied through the clipboard;
- local UI, storage, pricing and workflow configuration;
- application logs.

The official HTTPS service receives data required for licensing, version
checks and server-assisted pricing, such as a license/session identifier,
hardware-bound activation data, application version and pricing requests.
Network infrastructure necessarily receives connection metadata such as an IP
address.

Full support logs are not intended for public GitHub Issues. They are sent
only when the user explicitly chooses the in-app support action. Users should
review and avoid publishing secrets or unrelated personal data.

This public repository contains no live account session, wallet, proxy,
operator database or private source tree.
