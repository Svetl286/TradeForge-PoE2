# Privacy summary / Кратко о конфиденциальности

TradeForge is a desktop automation application. Its advertised operation may
process the following data locally:

- configured screen regions and templates;
- mouse and keyboard automation state;
- Path of Exile 2 item text copied through the clipboard;
- local UI, storage, pricing and workflow configuration;
- application logs.

The official HTTPS service receives data required for licensing, version
checks and server-assisted pricing, such as a license/session identifier,
hardware-bound activation data, application version and pricing requests.
Network infrastructure necessarily receives connection metadata such as an IP
address.

Full support logs are not intended for public GitHub Issues. They are sent
only when the user explicitly chooses the in-app support action. Users should
review and avoid publishing secrets or unrelated personal data.

This public repository contains no live account session, wallet, proxy,
operator database or private source tree.

## Русский

TradeForge — настольная программа автоматизации. Во время заявленной работы
она может локально обрабатывать настроенные области экрана и шаблоны, состояние
управления мышью и клавиатурой, текст предметов Path of Exile 2 из буфера
обмена, пользовательские настройки и журналы программы.

Официальный HTTPS-сервис получает только данные, необходимые для лицензии,
проверки версии и серверной оценки: идентификатор лицензии/сессии, данные
активации с привязкой к устройству, версию программы и запросы оценки. Сетевая
инфраструктура неизбежно получает технические метаданные соединения, включая
IP-адрес.

Полные логи нельзя публиковать в GitHub Issues. Они отправляются только после
явного действия пользователя во встроенной форме поддержки. Перед отправкой
необходимо исключить секреты и посторонние персональные данные.

Публичный репозиторий не содержит рабочих сессий аккаунтов, кошельков, прокси,
операторских баз данных или закрытого дерева исходного кода.
